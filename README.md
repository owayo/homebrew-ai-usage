# homebrew-ai-usage

[Homebrew](https://brew.sh) tap for
[**ai-usage**](https://github.com/owayo/ai-usage) — unified Claude + Codex +
Antigravity usage limits across Chrome profiles (macOS only).

## Install

```bash
brew install owayo/ai-usage/ai-usage
```

Or, equivalently:

```bash
brew tap owayo/ai-usage
brew install ai-usage
```

## Update

```bash
brew update
brew upgrade ai-usage
```

## Uninstall

```bash
brew uninstall ai-usage
brew untap owayo/ai-usage
```

## About

`Formula/ai-usage.rb` is regenerated automatically by the
[release workflow](https://github.com/owayo/ai-usage/actions/workflows/release.yml)
in the main [ai-usage](https://github.com/owayo/ai-usage) repository — do not
edit it by hand. Bottle assets (`arm64_sonoma`, `sonoma`) are attached to each
GitHub Release in that repository. See ai-usage's
[README](https://github.com/owayo/ai-usage#readme) for full documentation.
